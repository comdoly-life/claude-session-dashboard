위쪽이 대시보드 창, 구분선 아래가 프롬프트 바로 위에 붙는 두 줄입니다. 화면 문구는 한국어입니다.

  • 회색고르지 않은 버튼
  • 주황고른 모델
  • 파랑고른 effort
  • 보라울트라코드 켜짐

설치

  1. Claude Code 버전 확인 Claude Code 2.1.300 이상이 필요합니다. 셸에서 확인하세요. 
    claude --version
  2. 설치 명령 실행 Claude Code 터미널 세션의 프롬프트에 붙여 넣고 Enter를 누릅니다. 
    /plugin install session-dashboard --marketplace comdoly-life/claude-session-dashboard
    셸에서 설치하려면: 
    claude plugin install session-dashboard --marketplace comdoly-life/claude-session-dashboard
  3. 질문에 답하기 마켓플레이스를 추가할지 물으면 y를 누르고, 설치 범위를 고릅니다. 모든 프로젝트에서 쓰려면 user(기본값), 이 프로젝트에서만 쓰려면 project나 local을 고르세요.
  4. 불러오기 이미 열려 있는 세션이면 /reload-plugins를 실행하고, 아니면 새 세션을 시작합니다. 프롬프트 위에 두 줄이 생기고, 터미널이 충분히 넓으면 대시보드 창이 옆에 열립니다. 
    /reload-plugins

사용법

하고 싶은 것방법
대시보드 창 열기·닫기/dash
버튼 누르기전체 화면 모드에서는 마우스로 클릭합니다. 키보드로는 ctrl+x 다음 tab으로 버튼 줄에 들어가 Tab으로 옮기고 Enter로 누릅니다.
모델 바꾸기페이블·오푸스·소넷·하이쿠 중 하나를 누르면 그 계열의 최신 모델로 바뀝니다. /model과 같아서 새 세션의 기본값으로도 저장됩니다.
effort 바꾸기low부터 max까지 누릅니다. /effort와 같고, 턴이 돌고 있으면 그 턴이 끝난 뒤 적용됩니다.
울트라코드 켜고 끄기울트라코드 버튼을 누릅니다. 이 세션에만 적용됩니다.
세부 내용 보기대시보드 창에서 항목을 클릭하면 탭이 열립니다. 맡은 일, 지금 하는 일, 토큰 내역, 할 일, 최근 호출을 보여 줍니다.

한도 막대는 전체 중 쓴 만큼을 칠하고 남은 비율을 숫자로 씁니다. 남은 양이 60% 이상이면 초록이고, 줄어들수록 주황에서 진한 빨강으로 바뀝니다.

울트라코드와 워크플로

울트라코드는 이 세션의 모든 작업을 워크플로로 돌립니다. 워크플로는 일을 여러 에이전트에게 나눠 맡겨 동시에 처리하는 방식이라, 결과는 꼼꼼해지지만 토큰을 훨씬 많이 씁니다.

워크플로 기능(/config의 Dynamic workflows)은 워크플로를 쓸 수 있게 하는 스위치입니다. 켜져 있으면 "워크플로로 해 줘"처럼 직접 요청할 때만 워크플로가 돌고, 꺼져 있으면 아예 쓰지 않습니다.

그래서 이 mod에는 울트라코드 버튼 하나만 둡니다. 울트라코드를 켤 때 워크플로 기능이 꺼져 있으면 함께 켜고, 울트라코드를 꺼도 워크플로 기능은 켜 둡니다. 워크플로를 아예 막고 싶을 때만 /config에서 끄면 됩니다.

업데이트와 삭제

새 버전으로 올리기(적용하려면 Claude Code를 다시 시작합니다):

claude plugin update session-dashboard@claude-session-dashboard

지우기:

claude plugin uninstall session-dashboard@claude-session-dashboard

알아 둘 점

  • 5시간·주간 한도는 Claude 구독으로 로그인했을 때만 나옵니다. API 키로 쓰면 한도 줄이 없습니다.
  • 네트워크로 아무것도 보내지 않습니다. 세션의 이벤트와 세션 폴더의 워크플로 기록만 읽습니다.
  • 터미널이 좁으면 막대가 짧아지거나 빠지고, 버튼 묶음이 다음 줄로 넘어갑니다.
  • 처음 켤 때와 /clear 뒤에는 지금 모델과 그 모델에 저장된 effort를 바로 표시합니다.

In English

A Claude Code mod with a live pane of the main session, subagents, agent teams and workflows (what each is doing, progress, tokens and run time), and two rows above the prompt: the 5-hour / weekly limit bars with what is left, and chips for the model, effort and ultracode. The UI text is in Korean. It needs Claude Code 2.1.300 or later. To install, run this at the prompt of a Claude Code terminal session, answer y to add the marketplace, then pick a scope:

/plugin install session-dashboard --marketplace comdoly-life/claude-session-dashboard
